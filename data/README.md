# Dados do protótipo

- `perfil_investidor.json`, `transacoes.csv` e `historico_atendimento.csv` começam
  vazios. Não existe personagem ou situação financeira predefinida.
- `produtos_financeiros.json` é um catálogo educacional de categorias, não uma
  oferta comercial.
- `fontes_oficiais.json` registra as referências e a data de verificação.

Não adicione CPF, número de conta, senha, token, extrato real ou qualquer outro
dado pessoal/confidencial a esta pasta.

Durante uma conversa, a Lary usa temporariamente apenas as informações que a
pessoa decidir fornecer. A aplicação não grava esses dados nos arquivos.
